History

Notes: Hebrew uses Mispar Hechrachi (finals = base value); English text in the Hebrew cipher uses the common "Jewish" Latin mapping. Latin uses Agrippa's 23-letter table (J→I, U→V, W→VV). Greek (English) transliterates Latin letters to Greek (th→θ, ph→φ, ch→χ, ps→ψ) then applies isopsephy. Isopsephy works on Greek script, including archaic ϛ/ϝ=6, ϙ=90, ϡ=900.
